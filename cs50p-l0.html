第0讲 · 函数与变量

本讲地图

学什么：让电脑在屏幕上显示文字（print）、问你问题并记住答案（input 和变量）、处理文字和数字，最后自己造一个函数（def）。

为什么：后面九讲全都建立在这一讲上。以后调 AI 接口，本质也是「把文字交给一个函数，拿回它的结果」。

学完能做：写一个会问你名字、跟你打招呼、帮你算账的小程序。

建议日程（每天 2～3 小时）

  • 第 1 天 第 0 步准备（在路线图里）+ 分段 1～3
  • 第 2 天 分段 4～6
  • 第 3 天 分段 7～8 + 过关测验
  • 第 4 天 练习题 5 道
  • 第 5 天 英语遍（可以分两次看完）

每天开始前先刷 15 分钟 Anki（只开「第0讲」那一组）。下面每一步做完就勾上，进度会记在这台手机上，路线图会显示到哪了。

第 2 步 · 分段看课 1/8

第一个程序

▶ 视频 0:00 – 12:50

看的时候注意

  • 代码就是一行行文字，写在编辑器（老师用的 VS Code）里。
  • 终端是敲命令的窗口。python hello.py 的意思是：让 Python 运行 hello.py 这个文件。
  • bug = 程序里的错误。老师会故意写错给你看。

亲手敲（Termux）

在 Termux 里先建一个练习文件夹，以后都在这里写：mkdir ~/cs50 回车，cd ~/cs50 回车。然后输入 nano hello.py 打开编辑器，写下这一行：

print("hello, world")
屏幕上会看到
hello, world

写完按 Ctrl+O（O 是字母）再按回车保存，按 Ctrl+X 退出。然后在终端输入 python hello.py 运行。Ctrl 在 Termux 键盘上方那排键里。

故意犯个错

把 print 故意拼错成 prnt：

prnt("hello, world")
报错最后一行
NameError: name 'prnt' is not defined. Did you mean: 'print'?

NameError = 不认识这个名字。Python 3.14 还会猜你想写的是 print。

把最后的右括号删掉：

print("hello, world"
报错最后一行
SyntaxError: '(' was never closed

SyntaxError = 语法错误，这里是括号没配对。

看懂了吗

这行代码运行后，屏幕上显示什么？
print("hello, world")
在终端里输入 python hello.py，是在做什么？
第 2 步 · 分段看课 2/8

input 和变量

▶ 视频 12:50 – 20:10

看的时候注意

  • input("问题") 会显示问题、等你输入，然后把你输入的文字交回来。
  • name = input(...)：= 不是「等于」，是把右边的结果存进左边的名字里。这个名字就叫变量。
  • print 里用逗号隔开两样东西，它会自动在中间加一个空格。

亲手敲（Termux）

把 hello.py 改成这样（nano hello.py 打开修改）：

name = input("What's your name? ")
print("hello,", name)
运行后输入 David 再回车
屏幕上会看到
What's your name? David
hello, David

第一行：问名字，把答案存进 name。第二行：印出 hello, 再印出 name 里存的东西。

故意犯个错

把 name 放进引号里：

name = "David"
print("hello, name")
屏幕上会看到
hello, name

放进引号就变成了普通文字 "name"，不再是变量。变量名不加引号。

看懂了吗

运行后显示什么？
name = "Ann"
print("hello,", name)
x = 5 这行代码的意思是？
第 2 步 · 分段看课 3/8

注释、伪代码、print 的多个参数

▶ 视频 20:10 – 29:30

看的时候注意

  • # 后面的是注释，写给人看，电脑跳过不执行。
  • 伪代码 = 先用人话（注释）把步骤写下来，再一步步换成代码。
  • + 能把两段文字直接拼在一起，中间不加空格；逗号隔开则会加空格。

亲手敲（Termux）

# 问名字
name = "David"
# 两种打招呼的写法
print("hello, " + name)
print("hello,", name)
屏幕上会看到
hello, David
hello, David

两行结果一样：第一种是自己在 "hello, " 末尾留了空格再拼接，第二种是 print 自动加空格。

看懂了吗

运行后显示什么？
print("a" + "b")
这段代码运行后显示几行？
# print("one")
print("two")
第 2 步 · 分段看课 4/8

读文档：print 的 sep 和 end，引号

▶ 视频 29:30 – 44:10

看的时候注意

  • 老师会打开 Python 官方文档。不用全看懂，知道「函数能做什么，查文档」就行。
  • print 默认在结尾换行（end="\n"），多个参数之间默认用空格隔开（sep=" "）。都可以改。
  • \n 代表换行。文字里要放双引号，可以外面改用单引号，或者写成 \"。

亲手敲（Termux）

print("hello,", end="")
print("David")
屏幕上会看到
hello,David

第一个 print 的结尾改成了空的，所以不换行，第二个紧接着印在同一行。

print("a", "b", "c", sep="-")
屏幕上会看到
a-b-c

sep 改成了 -，所以用横杠代替空格隔开。

print('He said "hi"')
屏幕上会看到
He said "hi"

外面用单引号，里面的双引号就能原样印出来。

看懂了吗

运行后显示什么？
print("1", "2", sep="")
运行后显示什么？
print("a", end="!")
print("b")
第 2 步 · 分段看课 5/8

f 字符串和处理文字

▶ 视频 44:10 – 60:30

看的时候注意

  • f 字符串：引号前加 f，{变量} 会被换成变量的值。比逗号、加号都清楚。
  • 文字（字符串）自带很多功能：strip() 去掉两头空格，title() 每个词首字母大写，split() 拆开。
  • 可以连着用：name.strip().title()，从左往右依次执行。

亲手敲（Termux）

name = "  david malan  "
name = name.strip().title()
print(f"hello, {name}")
屏幕上会看到
hello, David Malan

先去掉两头空格，再把每个词首字母大写，最后用 f 字符串放进句子里。

first, last = "David Malan".split(" ")
print(f"hello, {first}")
屏幕上会看到
hello, David

split(" ") 按空格拆成两段，分别存进 first 和 last。

故意犯个错

忘了在引号前加 f：

name = "David"
print("hello, {name}")
屏幕上会看到
hello, {name}

没有 f，花括号就只是普通字符，原样印出来。

看懂了吗

运行后显示什么？
print("  hi  ".strip() + "!")
运行后显示什么？
x = "bob"
print(f"I am {x.title()}")
第 2 步 · 分段看课 6/8

整数 int

▶ 视频 60:30 – 74:35

看的时候注意

  • 交互模式：终端里只输入 python 回车，出现 >>> 就能一行一行试。输入 exit() 退出。
  • input 拿到的永远是文字。"1" + "2" 是拼接成 "12"，不是 3。
  • int() 把文字变成整数。可以套着写：int(input(...))，里面先执行。

亲手敲（Termux）

在 Termux 输入 python 进入交互模式，试试 1 + 2、7 / 2、7 % 2。然后写一个计算器文件 calculator.py：

x = int(input("x: "))
y = int(input("y: "))
print(x + y)
运行后输入 1 2 再回车
屏幕上会看到
x: 1
2
y: 3

运行后先输入 1 回车，再输入 2 回车，会显示 3。

故意犯个错

去掉 int，直接相加：

x = "1"
y = "2"
print(x + y)
屏幕上会看到
12

两段文字相加就是拼起来，所以是 12。算数之前先 int()。

给 int 一个不是数字的东西：

int("cat")
报错最后一行
ValueError: invalid literal for int() with base 10: 'cat'

ValueError = 值不对，cat 没法变成整数。第 3 讲会学怎么处理这种错。

看懂了吗

运行后显示什么？
print(int("3") + int("4"))
运行后显示什么？
print(7 % 3)
第 2 步 · 分段看课 7/8

小数 float、四舍五入、格式化

▶ 视频 74:35 – 86:30

看的时候注意

  • float = 带小数点的数。/ 除法的结果总是 float，哪怕刚好除尽。
  • round(x) 四舍五入成整数，round(x, 2) 保留两位小数。
  • f 字符串里加格式：{z:,} 加千分位逗号，{z:.2f} 保留两位小数。

亲手敲（Termux）

print(10 / 2)
print(round(3.14159, 2))
print(f"{1000000:,}")
print(f"{2/3:.2f}")
屏幕上会看到
5.0
3.14
1,000,000
0.67

10/2 是 5.0 不是 5；3.14159 保留两位是 3.14；一百万加上逗号；2/3 保留两位是 0.67。

看懂了吗

运行后显示什么？
print(9 / 3)
运行后显示什么？
z = 1234.5
print(f"{z:,.1f}")
第 2 步 · 分段看课 8/8

自己定义函数

▶ 视频 86:30 – 1:45:37

看的时候注意

  • def 名字(参数): 定义一个函数，下面缩进的几行都属于它。
  • 参数可以有默认值：def hello(to="world")，调用时不传就用默认的。
  • Python 从上往下执行，函数要先定义再调用。所以习惯是写一个 main()，在文件最后一行调用 main()。
  • return 把结果交回给调用的人。print 只是显示，return 才能让别人接着用这个结果。

亲手敲（Termux）

def main():
    name = "David"
    hello(name)
    hello()

def hello(to="world"):
    print("hello,", to)

main()
屏幕上会看到
hello, David
hello, world

最后一行才真正开始运行：main 先用 David 调用 hello，再不带参数调用一次，就用默认的 world。

def square(n):
    return n * n

print(square(3) + 1)
屏幕上会看到
10

square(3) 交回 9，再加 1 得 10。如果 square 里只写 print 不写 return，就没法接着加 1。

故意犯个错

在定义之前就调用：

hello()

def hello():
    print("hi")
报错最后一行
NameError: name 'hello' is not defined. Did you mean: 'help'?

运行到第一行时 hello 还没定义。这就是要写 main()、并在最后才调用它的原因。

函数体忘了缩进：

def hello():
print("hi")
报错最后一行
IndentationError: expected an indented block after function definition on line 1

IndentationError = 缩进不对。def 下面那几行必须往里缩（一般是 4 个空格）。

看懂了吗

运行后显示什么？
def hi(name="you"):
    print("hi,", name)

hi("Ann")
hi()
运行后显示什么？
def double(n):
    return n * 2

x = double(5)
print(x + 1)

第 4 步

练习题

这是哈佛官方的第 0 套作业。下面是题意概述和一层一层的提示，先自己想，卡住了再点开下一层。都在 Termux 的 ~/cs50 里用 nano 文件名.py 写，python 文件名.py 运行。官方的提交和自动打分需要 GitHub 账号和 cs50.dev，先不用管，能按示例跑出正确结果就算过。
1. Indoor Voice（小声说话） 官方题目 ↗

文件名 indoor.py。让用户输入一句话，把它全部变成小写再印出来，标点和空格保持不变。

试运行：
$ python indoor.py
HELLO, World!
hello, world!
提示 1

要用到 input() 拿到用户的话。

提示 2

字符串有个方法能把所有字母变小写，和 title() 是一类东西。

提示 3

.lower()

2. Playback Speed（放慢语速） 官方题目 ↗

文件名 playback.py。让用户输入一句话，把里面的每个空格换成 ...（三个点）再印出来。

试运行：
$ python playback.py
This is CS50
This...is...CS50
提示 1

思路：拿到输入 → 替换 → 打印。

提示 2

字符串有个方法叫 replace，接收两个参数：要被换掉的、换成什么。

提示 3

.replace(" ", "...")

3. Making Faces（表情转换） 官方题目 ↗

文件名 faces.py。写一个函数 convert，收到一段文字后，把里面的 :) 换成 🙂、:( 换成 🙁，然后返回结果。再写一个 main：让用户输入、调用 convert、印出结果。文件最后调用 main()。

试运行：
$ python faces.py
Hello :)
Hello 🙂
提示 1

结构照着分段 8 的 main + hello 那个例子写。

提示 2

convert 里连着用两次 replace，最后要 return，不是 print。

提示 3

return text.replace(":)", "🙂").replace(":(", "🙁")

4. Einstein（质能方程） 官方题目 ↗

文件名 einstein.py。按 E = mc² 计算：让用户输入质量 m（整数，单位千克），光速 c 取 300000000，印出能量 E（整数）。

试运行：
$ python einstein.py
m: 1
E: 90000000000000000
提示 1

input 拿到的是文字，要先 int()。

提示 2

Python 里求平方用 ：c 2。

提示 3

E = m * 300000000 ** 2

5. Tip Calculator（小费计算器） 官方题目 ↗

文件名 tip.py。官方页面给了大半代码，你只需要补完两个函数：dollars_to_float 收到像 $50.00 的文字，去掉 $，返回小数 50.0；percent_to_float 收到像 15% 的文字，去掉 %，返回 0.15。代码从官方页面抄过来。

试运行：
$ python tip.py
How much was the meal? $50.00
What percentage would you like to tip? 15%
Leave $7.50
提示 1

两个函数都是：去掉一个符号 → 转成 float → return。

提示 2

去掉开头/结尾的字符可以用 replace("$", "")，或者 removeprefix("$") / removesuffix("%")。

提示 3

百分比记得除以 100：return float(p.removesuffix("%")) / 100
