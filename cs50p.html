CS50P 学习路线

哈佛 Python 入门课，从零开始。目标：能自己写小程序，并且不看字幕听懂这门课。每天 2～3 小时，大约 7～8 周。

这套东西怎么用

每一讲都按同样的 5 步走，一讲大约 4～5 天：

  • 课前：刷这一讲的 Anki 生词，混个脸熟。
  • 分段看课：中英字幕版视频切成 15～20 分钟一段。每段先看「注意什么」，看完在 Termux 里亲手敲代码、故意犯错，再做两道小题。
  • 过关测验：做这一讲的复习题，答对 8 成再往下。
  • 练习题：哈佛官方作业，附中文题意和一层层的提示。
  • 英语遍：原版视频只开英文字幕再看一遍，再刷原声语块卡。

每天固定：开始学之前刷 15 分钟 Anki，只刷学到的那几讲。

英语怎么一步步撤字幕：第 0～3 讲第二遍开英文字幕；第 4～6 讲第二遍试试不开字幕；第 7～9 讲第一遍就直接看英文字幕版，中英版只在卡住时查。

第 0 步 · 准备（约 1 小时）

1. 装好 Anki 牌组
  • 如果 Anki 里已经有旧的 CS50P 牌组，先把它们删掉（长按牌组 → 删除），避免和新的混在一起。
  • 打开手机「文件」→ Download/转写/CS50P-全课/CS50P-全套.apkg，用 AnkiDroid 打开就会导入。
  • 导入后是 CS50P → 必背清单 / 第0讲…第9讲，每讲下面分生词、语块、复习题三组。
  • 只点开你正在学的那一讲来刷，不要点最外层的 CS50P（那样会把十讲混在一起）。
2. 学会在 Termux 里写和运行代码
  • 建一个练习文件夹：输入 mkdir ~/cs50 回车，再输入 cd ~/cs50 回车。以后每次打开 Termux 先 cd ~/cs50。
  • 写文件：nano hello.py 打开编辑器，写代码；Ctrl+O 再回车保存，Ctrl+X 退出。Ctrl 在键盘上方那排键里。
  • 运行：python hello.py。
  • 随手试一行：只输入 python 回车，出现 >>> 就能一行一行试，exit() 退出。
3. 看视频的地方
  • 中英字幕版在手机 Download/转写/CS50P-全课/，用相册或任意播放器打开。流程页里会写「看 12:50–20:10」，拖到对应时间就行。
  • 英文原版在 CS50P 官网，播放器能单独开英文字幕。
4. 热身（可选）

完全没碰过代码的话，先花 20 分钟点一遍 读代码入门 · 变量 和 判断，感受一下「读代码」是什么样。
