一、社会主义法治思维

法治思维：以法治价值和法治精神为导向，运用法律原则、规则、方法思考处理问题的思维模式。四层含义：正当性思维（以法治价值精神为指导）、规范性思维（以法律原则规则为依据）、逻辑思维（以法律手段方法分析处理问题）、符合规律尊重事实的科学思维。

法治思维的基本内容——五要素：

要素含义
法律至上法律是地位最高、效力最广、强制力最大的规范
权力制约国家机关权力必须受法律规制约束；一切权力属于人民、为民所有为民所用
公平正义政治、经济及其他利益在社会成员间合理公平地分配和占有
权利保障对公民权利的宪法保障、立法保障、行政保障、司法保障
程序正当合法性/中立性/参与性/公开性/时限性；只有依程序才能防止主观任性、保证结果公正有公信力

法律权利的四个特征：①内容种类和实现程度受社会物质生活条件制约——不能脱离一国经济社会发展阶段空谈权利；②因社会制度和国家法律不同而存在差异；③受法律维护保障，具有不可侵犯性；④必须依法行使，不能不择手段、不得任性。

二、常考的民事权利

权利要点
姓名权决定/使用/依规定变更自己姓名并维护其利益的具体人格权，含姓名决定权、使用权、变更权、许可他人使用权
名称权法人和非法人组织决定使用变更名称、排除他人非法干涉盗用冒用的具体人格权
肖像权四权——制作权、使用权、公开权、许可他人使用权；未经同意不得制作使用公开或利用信息技术伪造他人肖像；5 种情形可不经同意：个人学习艺术欣赏课堂教学科研必要范围内使用已公开肖像 / 新闻报道不可避免制作使用 / 依法履行职责必要范围内 / 展示特定公共环境不可避免 / 为维护公共利益或肖像权人合法权益
名誉权 / 荣誉权就自身属性和价值获得的社会评价享有的保有维护权利；为公共利益实施新闻报道舆论监督不承担责任，但捏造歪曲事实 / 未尽合理核实义务 / 使用侮辱性言辞贬损他人名誉三种情形除外；荣誉不得非法剥夺，记载错误可请求更正
隐私权对与公共利益无关的私人空间、私人活动、私人信息等私生活安全利益自主支配控制、不受他人侵扰的具体人格权；6 种侵害行为：电话短信等方式侵扰私人生活安宁 / 进入拍摄窥视私密空间 / 拍摄窥视窃听公开私密活动 / 拍摄窥视身体私密部位 / 处理私密信息 / 其他方式
个人信息保护能单独或结合识别特定自然人的各种信息（姓名、生日、身份证号、健康信息、行踪等）；私密信息适用隐私权规定；信息处理者不得泄露篡改，须采取技术措施防止泄露丢失，发生泄露须补救并告知报告

三、法律义务

法律义务是由社会物质生活条件制约的社会责任，是保证义务人按权利人要求作为或不作为以满足其利益的法律手段。履行形式：作为（如赡养父母的探望供养行为）与不作为（如不得公开他人隐私）。四个特点：历史的（随社会发展调整变化）、源于现实需要（受制度性质历史传统文化宗教等因素影响）、必须依法设定（坚持义务法定）、可能发生变化。
