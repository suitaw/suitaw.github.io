一、法律的含义及历史发展

法律：由国家制定或认可、并由国家强制力保证实施的、反映特定社会物质生活条件所决定的统治阶级意志的规范体系。国家强制性是法律规范区别于道德规范、纪律规范的关键特征（道德纪律也有一定强制力，但不以国家强制为后盾）。

国家创制法律规范的两种方式：①制定/修改/废止规范性文件；②赋予既存社会规范或先前判例以法律效力。

类型本质 / 特征
奴隶制法律奴隶主阶级专政意志的体现；有原始习惯残留、否认奴隶法律人格、严格等级划分、刑罚极其残酷。
封建制法律封建地主阶级统治农民的工具；确立人身依附关系、实行等级制度、维护专制皇权、刑罚严酷。
资本主义法律维护资产阶级政治经济社会秩序，价值原则是形式上的自由民主平等；私有财产神圣不可侵犯、契约自由、法律面前人人平等、人权保障（形式）四大原则。
社会主义法律以公有制为经济基础，最广大人民群众意志的集中体现，是实现人民当家作主、人民民主专政的重要保证。

二、我国社会主义法律的本质特征

  1. 体现党的主张和人民意志的统一——党领导人民制定宪法法律，党自身也必须在宪法法律范围内活动。
  2. 具有科学性和先进性——坚持马克思主义世界观方法论，尊重反映社会发展客观规律。
  3. 是中国特色社会主义建设的重要保障——法的社会作用体现社会主义本质要求：经济发展、政治清明、文化昌盛、社会公正、生态良好。

三、法律的运行（制定 → 执行 → 适用 → 遵守）

法律制定是法律运行的起始性和关键性环节，全国人大及其常委会行使国家立法权，贯彻公正、公开原则，坚持科学立法、民主立法、依法立法。

立法主体权限
全国人大修改宪法、制定基本法律
全国人大常委会解释宪法、制定其他法律
国务院制定行政法规
国家监察委员会制定监察法规
中央军事委员会制定军事法规
国务院各部门本部门权限内制定部门规章
省 / 直辖市人大及常委会不抵触前提下制定地方性法规，报全国人大常委会备案
设区的市人大及常委会制定地方性法规，报省 / 自治区人大常委会批准后施行
省 / 自治区 / 直辖市 / 设区的市人民政府制定地方政府规章
自治区 / 自治州 / 自治县人大依民族政治经济文化特点制定自治条例、单行条例
特别行政区立法机关依基本法及法定程序制定法律

立法程序四环节：法律案提出 → 审议 → 表决 → 公布。

法律执行：广义指国家机关及公职人员依法定职权程序贯彻实施法律；狭义特指行政机关执法，须坚持合法性、合理性、信赖保护、效率等原则。

法律适用：国家司法机关及其公职人员依法定职权程序适用法律处理案件，要求正确、合法、合理、及时。

司法机关原则
人民法院依法独立行使审判权，不受行政机关、社会团体和个人干涉
人民检察院依法独立行使检察权，不受行政机关、社会团体和个人干涉

法律遵守：一切组织和个人依法行使权利、履行义务的活动。守法既是履行法律义务，也是依法享有并行使权利；是法律实施和实现的基本途径。
