  那个系数叫需用系数，本质是「按最坏情况选成本高得离谱，按平均选又频繁跳闸」
- **8.3 屏 4**：型号里 **32 是外壳的上限（架构等级）、25 才是这一只的额定电流**，

- **8.4 和 7.3 屏 4 是同一条推理换了个场地**：那边是「不亮的范围有多大，
  故障就在多大范围的公共部分上」，这边是「先查同级、再查上级」。
  文案里明说了这一点让两节互相咬住
- **8.4 屏 4 的「插卡看电量」是白送的一条**：书 P160 提示说明写着
  **还应考虑是否由于电能表预存电量耗尽引起的** —— 现象和线路故障一模一样
  （整户没电、总闸合着、外观正常），**而它根本不是故障**

**一处书上写得含糊、按国标教并注明的地方（8.2 屏 3）**：
书 P148 那句「将第 2、4 接线端子分别连接总断路器的**零线和相线**接线端」

### 7.1 一个灯，几个地方控（sec/c7-1.js，2026-08-30）

四屏：一开单控 → 双控（两地）→ 多控（三地）→ 三种接错。四屏都能**点画布上的开关**。

**这一节的眼是一句话**：单控开关做的是「通 / 断」，**双控开关做的是「换路」——
它从来不断开**。于是三屏能被同一句话串起来：从相线数到灯，
**每按一次开关就是翻转一次，翻偶数次灯亮、奇数次灯灭** ——
这就是为什么中间串几个多控开关、任意一个都能控灯。屏 3 的数字卡直接显示「一共翻转了 N 次」。

**书上的出处（别凭记忆改）**：
- 图 7-2 异地联控：两只双控 SA1、SA3 加一只**双控联动开关 SA2**（SA2-1 / SA2-2 两组触点联动），
  「**按下任意开关都可点亮照明灯 EL**」
- 书 P125：卧室要求**进门和床头都能控制** → 两地控制；客厅一般设计成**三方控制**
- 图 7-6：**一开单控 / 二开单控 / 一开双控**，文字标识都是 **S 或 SA**
- 图 7-9：相线接开关入线端、出线端去灯；**零线不经过开关，直接在接线盒内连接**

**自己加的、书上没有的三样，都在文案里标了出处口径**：
- **螺口灯座螺纹接零、中心舌簧接相线** —— 通行规范，注明「书上这一节没写」
- **端子标识 L / L1 / L2（也有印 COM、1、2 的）** —— 各厂家不同，钉死一句
  「**以面板背面印的为准**」，不编统一规则；拿不准就用通断档量，
  **两次都参与的那个端子就是公共端**
- **多控开关画成「两组联动的换向触点 + 直通/交叉」** —— 这就是书上 SA2-1/SA2-2 那两组，
  只是把作用直接标出来了，文案里说明了两种说法是同一件事

**屏 4 的三种接错，全画在同一个双控骨架上**（差别才跳得出来），
共同点就是这一屏的落点：**接错了灯照样会亮**，所以「装完试了下灯能亮」证明不了接对了。
- **① 少接一根联络线**（或公共端认错，症状一模一样）→ 四种组合只有一种亮，
  症状是「一个开关只在某个位置时，另一个才管用」
- **② 相线进 SA1、零线进 SA2、灯挂在两根联络线中间** → **一半的组合是短路**。
  拨到不同边时灯**真的亮**，拨到同一边当场跳闸 —— 最危险的一种，因为它一半时间是「好的」
- **③ 开关串在零线上** → 开关、两地控制全部正常，但**灯座常带 220 V**。
  查法：关掉开关拿验电笔点灯座，亮就是接反了

**数线（装之前先数，这是最实用的一条）**：第一个开关盒 单控 2 / 双控 3 / 三地 3，
中间开关盒 三地 **4**，末端开关盒 双控 3 / 三地 3，灯位盒一律 2（不含 PE）。
**关键是两个开关盒之间那两根联络线** —— 装修埋管只穿了一根，双控就做不了，只能重新穿线。

**这一节踩的坑（全是逐屏截图抓出来的）**：
- **通路不能整条 `glow`** —— 一发光就把红（相线）/ 灰（开关线）/ 蓝（零线）三段颜色全盖成橙色，

  `glow` 只留给「带电但走不到灯」那一段 —— 那才是没有圆点、需要另外标出来的情形
- **零线标签一律画在下面那根线的上方**（`NY - 13`）。放下方会被结论条整个盖掉，四屏一起栽
- **「电到这儿为止」那个胶囊和 SA 标签抢同一个高度** —— 屏 3 的 SA3 被整个盖没了。
  SA 标签统一下移到两根联络线**下方**（y=158）
- **屏 4 的 ✗ 和「联络线 2」标签叠在一起**：✗ 就画在断口上不能挪，

- **画布上的「实物 ↔ 符号」引线不要戳进标注文字里**：面板到开关那条虚线原来画到 `bx-24`，

### 这一批新增的三样工具（后面各章直接用）

- **`EC.hot(g,x,y,r,o)`** —— 画布上的**可点提示**：元件外面套一圈细虚线环；

### 3.1 手上的工具（sec/c3-1.js，2026-09-03 补做）

书上 3.1~3.4 四节（钳子／螺钉旋具／电工刀／扳手，P48~P56）合成一节，四屏：
① 钢丝钳的四个口 ② 六把钳子对六个活 ③ 螺钉旋具与电工刀 ④ 扳手与五个考点。

**这一节的骨架直接对着题库 7-C 组搭**：那五道题就是工具部分全部要考的东西，
屏 4 下半部把它们列成一张表。**书上的话和题库的话在两处打架，都按老规矩处理**
（照题库记、把真相写出来）：钳柄耐压书上没写、**题库按 500 V**，
而市面产品常印 1000V —— 文案里两个都说，注明「考试按题库答 500V」。

**内容上最值钱的三条**：
- **四个口的顺序是被杠杆逼出来的**：钳口→齿口→刀口→铡口，从尖端往轴心排。
  **铡口离轴心最近、阻力臂最短，所以最硬的活给它**。
  「钳口铡不断钢丝不是你劲不够，是那个位置力矩不够」——
  这句话比背四条用途管用
- **手柄是第五处，它什么活都不干**（题库第 250 题）。
  绝缘套按耐压 500V 做，**敲一下里面就可能裂了，而外观完好** ——
  绝缘工具的损坏几乎都是看不见的
- **电工刀那两个角度管两件事**：45° 管「切得进去」（太平划不破、太陡扎到铜），
  切进去之后翘到约 25°，**刀刃贴着线芯表面滑**，削的是绝缘层。
  一直保持 45° 往前推就是往铜里扎

**这一节踩的坑（都是逐屏截图抓出来的）**：
- **选中的元件被整个染成了蓝色** —— 直接违反「点中元件不许改它的真实颜色，
  只加一圈细蓝描边＋光晕」那条规矩。改成：钢就是钢、绝缘套就是红，
  选中只靠 `hot` 虚线环和下面的名字变色。（同一天在 7.3 的断路器 × 上也栽过一次，
  **这两条都是「拿语义色去表达状态」**）
- **活扳手第一版画成了几个白方块，认不出是扳手**（elec-icons 那条老经验：
  画完必须截图看，认不出的重画）。重画成「一个厚头 ＋ 一根柄，

#### 2026-09-09：能放大 + 照实物画（他的两条反馈）

他的原话：「**图不能放大，或者说做的太小了，我在手机上看不清具体细节或者说很费力**」

**「不能放大」是两处叠加，只修一处不够**：
- 页面 `<meta viewport>` 写着 `maximum-scale=1`，把**系统的双指缩放整个禁掉了**
- 就算放开系统缩放，整页放大会把工具栏一起拉变形。所以舞台自己带缩放

**缩放用改 viewBox 实现，不用 `transform: scale`**：改 viewBox 时
**线宽、端子热区、字号跟着一起放大**，放大以后螺丝孔真的变大、也真的更好点；
`transform+scale` 那套 stroke-width 保持屏幕尺寸，等于只把图拉开、字还是那么小。
- 全览是 0.4 倍（880 单位画在 352px 里），**7px 的孔位标注在屏幕上只有 2.8px** ——
  所以细节文字（`.p-mark`/`.p-tiny`）默认 `opacity:0`，**放大到 1.5 倍才显示**
  （`svg.zoomed` 类，`applyVB` 里 toggle）。全览时干净，放大后细节全在
- **没放大就不许拖**：全览时图本来就整个在框里，一拖只会把它推出屏幕，手机上还跟页面滚动抢手势
- **`panned` 标志用完必须自己清**（`pointerup` 后 80ms）：它只用来吞掉「拖完松手」
  那一下 click，留着不清的话**下一次点端子会被静默吞掉**（回归测试抓到的）
- **点分组 / 点「下一根」自动凑近看**（`fitTo`）：整张图 0.4 倍下端子只有 2px，
  点了「第 2 组」还得自己捏合着去找那几根线在哪儿。这一条是「实操感」的关键，
  逐根播放跟着当前那根走 = 盯着这两个端子接线

### 单页站 book.html（2026-08-28）—— 六节合成一个站

他的原话是「把书的内容做成学习网站」，问清楚之后要的是**整体感**：
左侧目录 + 右侧正文、章节之间不跳页。原来六个独立 HTML 看着像六个页。

**内容的唯一真相搬进了 `sec/c1-N.js`**，六个 `c1-N.html` 退化成薄壳（各 1.1KB）。
改内容只改 `sec/` 那一处，book.html 和薄壳页载入的是同一个文件。
模块形如 `ELEC.reg({id,title,tabs,html,init})`，由 `c1-N.html` 机械拆分而来
（正文一个字未改：拆之前先查过六个文件**零反引号、零 `${`**，模板字面量才敢这么用）。

**用动态 `<script>` 标签载入，不是 fetch。** fetch 载 HTML 片段在 `file://` 下会被
CORS 挡掉 —— 他本地双击打开就废了，我这边截图验证也走 file://。动态 script 没这个限制。

**「切走时收干净」是这套东西能成立的前提**，两件事，都不用改那六个模块一个字：
- **rAF 循环要能停**：每节尾部都有 `loop(...)`。翻三节就有三个循环在后台跑，手机会烫。
  `EC.loop` 改成返回 `{stop()}`（旧调用忽略返回值，向后兼容），运行时收集句柄
- **`window.addEventListener` 要能解绑**：每节各有一个 `resize` 监听，绑在 window 上，
  换 DOM 收不回来，切走后仍会触发、去摸已经卸载的 canvas。
  做法是 init 期间**临时拦截 `window.addEventListener`** 把注册记下来，切走时统一 remove
- **tabs 和正文都换成全新节点**（不是只换 innerHTML）：模块把监听器绑在 `#tabs` 元素本身，
  只换内容的话旧监听器会一路累积
- **id 冲突天然不存在**：六节都用 `sc0~sc3`/`tabs`/`pager`，但同一时刻只挂一节，所以
  `EC.$` 那个 `getElementById` 照旧能用。这也是没走「六节全塞进一页」的原因 ——
  那条路要改几百处 id，还会撞上六节同名的顶层 `const cur`/`scenes`/`draw1`

**`book.html` 里必须停掉 `ElecNav.init`**（`ElecNav.init = function(){}`）：
每节的 init 里都有一句 `ElecNav.init({ch,sec})`，那是给薄壳页用的 —— 它往 `.top h1`
挂 ▾ 和 click、再往 body 塞一个课表覆盖层。单页站的 h1 是常驻的，
切一节就再挂一次，六节翻下来会挂出六个 ▾、六个监听器、六层覆盖层。

**版式**：手机上侧栏是抽屉（☰ 在顶栏最左），≥900px 常驻 284px。
他主要在手机上看，**抽屉才是主形态**，常驻是宽屏的附赠。
正文区复刻原来那套 `.wrap`/`.stick`/`.tabs`，所以 `elec-page.css` 一个字没改，吸顶照旧。

**2.2 接触器**：机构动作四步 / 四种触点（动合动断的「常」＝线圈没电时）/
失压保护 + 自锁 / 交流直流与铭牌。短路环那一屏画了两条吸力曲线，
「有短路环就不再过零」是这一节的眼。

**2.3 继电器**：中间继电器（一个信号→多路隔离输出）/ 热继电器 / 时间继电器 / 八种图鉴。

- **热继电器那一屏的热模型是凑过检查点的，别再重算**：
  `dθ/dt = (x² − θ)/τ`，`τ = 120 s`，`θ ≥ 1.15²` 动作（x = 实际电流 / 整定电流）。
  算出来 **1.05 倍永不动作 / 1.2 倍 5.0 分 / 1.5 倍 1.8 分 / 7.2 倍 3.1 秒 / 20 倍 0.4 秒** ——
  正好卡在国标那几个检查点里（1.05 倍 2 小时不动作、1.5 倍 2 分钟内、10A 级 7.2 倍 2~10 秒）。
  演示时间乘 **30 倍**，画布上明写了这一条。**动作之后按 x=0 冷却**（接触器已经把主电路断了），
  所以那根条会自己往下掉 —— 这也是「没凉透按不动复位」能演出来的原因
- **`θ` 在额定电流下稳定在 76%**，所以热量条的警戒线要设在 **0.8 / 0.95**，
  按 0.5 分档的话「正常运行」也是橙的，看着像出事了
- **数字卡里的百分比必须每帧更新**（`S2.lastHp` 比对后再写）：只在 `note2()` 里写一次的话，
  动作那一刻冻在 100%，而画布上那根条一直在降 —— 同一个数在一屏里出现两遍且对不上
- **延时触点那把「伞」的朝向，我没有把握，文案里如实写了**。
  查证过的只有「靠触头符号的降落伞朝向区分通电/断电延时」这句（题库 md 里也是这么说的），
  但具体哪一面朝哪边各版本画法有出入。所以课文教的是**可靠的三步**：
  先看线圈类型 → 再看动合还是动断 → 看旁边标的延时值。**别去补一条编出来的朝向规则**
- **「按什么原理延时」和「按什么方式延时」是两回事**（考试的坑）：
  原理＝空气阻尼/电磁/电动/电子；方式＝通电延时/断电延时。没有「电压式、电流式」这种分法
- 电流继电器 vs 电压继电器：**串/并、粗少/细多**。这条跟电流表串、电压表并是同一条规律，
  第 3 章还会再用一次

**这一节画布上踩的坑（都是截图抓出来的）**：

**2.4 传感器**：它干什么 / 测温度 / 光·湿·气 / **接近开关 NPN 与 PNP 怎么接**。
最后一屏是按「就业导向」加的重头戏 —— 书上没有，但工厂维修电工天天碰。

- **四条温度曲线的公式都有出处，别凭记忆改数**：
  NTC 是 B 值模型（R25 = 10 kΩ、B = 3950）；
  **Pt100 用 Callendar–Van Dusen 正温段 `R = 100(1 + 3.9083e−3·T − 5.775e−7·T²)`**，
  查一个点：100 ℃ → 138.5 Ω；K 型热电偶取 `E ≈ 0.041·T` 毫伏（线性近似，
  100 ℃ 约 4.1 mV、200 ℃ 约 8.2 mV）；
  **PTC 是按 DIN 44081（电动机埋置式热保护）那几个检查点凑的** ——
  `R = 80 + 300·exp((T−120)/3.5) Ω`，Tref = 120 ℃，
  算出来 100 ℃ 时 82 Ω、115 ℃ 时 152 Ω、125 ℃ 时 1330 Ω、135 ℃ 时两万多欧，
  正好卡在「Tref−20K ≤250 / Tref−5K ≤550 / Tref+5K ≥1330 / Tref+15K ≥4000」里
- **这类元件的阻值跨几百上千倍，纵轴必须走对数**，线性画出来大半段贴地。
  `curve()` 里 `ylog` 就是干这个的；Pt100 和热电偶够直，走线性
- **NPN / PNP 那一屏，两种接法只让「负载另一端接哪根母线」这一处不同**，
  其余画面完全一样 —— 差别才跳得出来。记法写成「NP**N** → 接**负**（0V）、
  PN**P** → 接**正**（24V）」，比背「漏型源型」可靠
- 选型口诀（钉死在文案里）：**PLC 输入公共端接 ＋24V 就配 NPN，接 0V 就配 PNP**。
  接错**不会烧**，只是没输入 —— 所以特别难查
- 坑：**元件本体上的文字和内部走线要分左右站**。
  「NPN / 接近开关」两行原来居中，内部那条竖线正好从字中间穿过去；
  改成文字靠右（`al:'right'`）、走线走左边（`INX = SW.x + 16`）
- 坑：**母线的标注只能放在母线上方**。「0V」放在下方会被底下那条结论条盖住
- 坑：`EP.readout`（LCD 读数）自带背景波纹，数字要够粗才压得住

**2.5a 电子元器件（上）**：读色环 / 电容充放电 / 电感反电动势 / 符号与万用表。

- **第 1 屏是个色环读数器**：四个 `<select>` 换颜色，实时算阻值 + 误差区间 + 逐环解读，
  底下还有一张颜色对照表（正在用的那几个描一圈）。
  为它给 `EP.resistor` 加了一个 `wide` 选项 —— **把误差环往右挪一截**。
  实物上误差环就是离另外三环远的，而「把离得远的那一头朝右」正是读色环的第一步；
  图上不拉开这段距离，教材里那句话就没法对着图讲。不传 `wide` 跟原来一模一样
- **区间要用同一个单位写**（`rangeText()`）：`950 Ω ~ 1.1 kΩ` 这种混着写既难比，
  还会把数字卡撑成两行
- RC / RL 的模型和参数：E = 12 V；电容屏 R 2~100 kΩ、C 10~470 μF（τ = RC）；
  电感屏 R 固定 2 Ω、L 0.5~5 H（τ = L/R，稳态 6 A）。
  **断闸的反电动势用一个 20 ms 的「弧时间」模拟**，UL = −L·di/dt 冲到几百伏 ——
  画面上写明了是量级示意，真实值取决于断开速度和杂散参数。
  勾上续流二极管后电流在小回路里按 τ = L/R 泄掉、UL 被钳在 −0.7 V，对比一目了然
- **「电感量出来只有几十欧是正常的」这条要专门讲**：那是铜线的直流电阻，
  不是短路。量接触器线圈的人十有八九在这儿犯嘀咕

**这一节的三个坑（前两个是老坑又犯）**：
- **每帧在变的量，必须每帧写进数字卡**（`lastUc` / `lastI` / `lastU` 比对后再写）。
  只在 `note()` 里写一次的话，屏幕上那张卡会冻在点按钮那一刻的值，
  而画布上的曲线一直在动 —— **同一个数在一屏里出现两遍且对不上**。
  2.4 的热量百分比刚栽过，这里又栽了两处
- **「峰值」这类值不能在点按钮那一刻读**：尖峰是断闸之后几帧才算出来的，
  `note3()` 在点击时执行时它还没发生，于是讲解里写成了「峰值到了 12 V」（合闸时的值）。
  做法是把峰值记录限定在「断闸且没加二极管」期间，等电流泄完再补调一次 `note3()`
- **`g.arc()` 的第 6 个参数 `true` 是逆时针**：电解电容那一极是一段向外凸的**短弧**，
  加了 `true` 会画成一个几乎闭合的大圆环

**2.5b 电子元器件（下）**：二极管 / 整流 / 晶体管当开关 / 晶闸管调压。
书上按「器件」讲，我按**现场会碰到什么**排：二极管 → 整流（控制变压器后面那块板子）
→ 晶体管当开关（PLC 输出、驱动继电器）→ 晶闸管（调压、软启动、固态继电器）。
放大电路那套是电子专业的活，只点一句。

- **整流三档的直流值是按画出来的那条曲线现算平均值的**，不是写死 0.45/0.9/1.2 ——
  图和数字卡永远对得上。跑出来正好是 **0.450 / 0.900 / 1.213 × U₂**（别再重算）。
  滤波那档 τ 取 **2.0 个半周**（≈20 ms @50Hz，中等负载），谷值 0.70×峰值。
  τ 是调出来的：2.8 给 1.255、1.6 给 1.182，2.0 正好落在教材那个 1.2 上
- **「12 V 变压器在直流侧量出 15 V」不是变压器坏了**：带电容滤波本来就是 1.2~1.4 倍。
  这条是现场最常见的误判之一，文案和课末练习都写了
- **晶闸管那一屏的公式有检查点**（别再重算）：单向半波、阻性负载，
  `Urms = U·√( [(π−α) + sin(2α)/2] / 2π )`。α=0 → 155.6 V（=0.707U，半波正弦有效值）、
  Uav=99 V（=0.45U，跟上一屏半波整流对得上）；**α=90° → 110 V，功率正好是 α=0 时的一半**；
  220V/100W 灯 R=484 Ω，α=0 时 P=50 W —— 只有额定的一半，因为负半周整个丢掉了。
  <b>这一条要在文案里说死</b>，否则「调到最亮也只有一半」看着像 bug；真正的调光器用双向晶闸管
- **BJT 和 MOSFET 的「饱和区」是反义词，绝对不能混着教**：BJT 的饱和 = 全导通，
  MOSFET 的饱和区却是恒流那一段。所以场效应管这边一律说「截止 / 过渡 / 完全导通」，
  不碰那两个词。BJT 那边照旧「截止 / 放大 / 饱和」
- 两种管**共用同一个负载**（12 V / 100 Ω，封顶 117 mA），横着比才有意义。
  MOSFET 取 Uth=4 V、`Id = 13(Ugs−4)²` mA，算出来 Ugs=7 V 时正好顶到 117 mA
- **指针表红表笔是表内电池的负极**，判二极管极性时跟数字表正好相反 —— 这条考证要考，写进课文了

**这一节画布上踩的坑（都是截图抓出来的）**：
- **特性曲线框底要专门留一条 32px 的「区名带」**：曲线画到框底的话，
  当前点那颗圆点和它的虚引线正好压在区名上。区名也不能放框顶 —— 那儿有纵轴名字和
  「被负载卡死在 117 mA」
- **太窄的区不写名字**（判据：宽度 < 44px 就跳过）。晶体管的截止区只有 Ib=0 那一个点，
  硬写的话文字从框左边溢出去
- **交流源的标注要放它右边**，放正下方会被底下那根回流导线穿过去；
  而「变压器副边」那一行伸出去又正好撞上桥式左边那个「～」—— 干脆删掉并进画布标题
- **桥式那一块横向很挤**：负载的名字要放电阻**上方**（放左边撞滤波电容的极板），
  滤波电容的名字要放极板**下方**（放左边撞右边那个「～」）
- **波形图的说明文字只能放左下角**：右上角在滤波档被输出曲线压住，正下方被输入正弦的负半周穿过
- **绿色虚线（直流平均值）上不要再挂胶囊标签**：滤波档它正好落在输出曲线上。
  图例和结论条已经把这个数说清楚了

**2.6 变压器**：匝数比 / 电柜里的四种 / 互感器两条铁律 / 怎么量怎么判坏。
书上只讲单相三相两种结构，我按**电柜里真会碰到的**排。

- **第 1 屏的眼是「三对柱子」**：匝数、电压、电流各画一对横条，
  每对按自己那组的最大值归一化 —— <b>匝数和电压那两对形状一模一样，电流那对正好反过来</b>。
  「电压比 = 匝数比、电流比反过来」这句话，画成这样比写公式管用
- **自耦变压器那一屏是安全课，不是省材料课**：公共段画成红的，
  配一条「一次 ⟷ 二次：直接连通，没有安全隔离」。
  结论钉死：**需要人身安全隔离的场合必须用隔离变压器，自耦调压器顶不了**
- **互感器两条铁律**：CT 二次不许开路、PT 二次不许短路。
  记法写成「CT 工作在接近短路的状态所以怕开路，PT 工作在接近空载所以怕短路」，
  跟第 1 章「电流表串、电压表并」是同一条线索。
  CT 二次额定 5 A、PT 二次额定 100 V 是标准值
- 三相电力变压器画的是**配电系统图上的双圆符号 + Dyn11**，不是三柱铁芯写实图 ——
  他上班拿到手的是系统图

**这一节画布上踩的坑**：
- **PT 的两根母线要拉得很开、整台 PT 画在它们中间**。母线挨着画的话，
  二次那圈回路会横穿过母线，看着像接在上面（截图抓到的）
- **CT 的「✗」要画在真正断开的那个缺口上**。画在旁边空地上看着像个装饰，
  而且导线仍然是连着的 —— 图自己打自己的嘴
- **母线的名字要放左端**，居中的话正好压在环形铁芯上
- **万用表表笔线要绕着外壳走**（左边走 x=80、右边走 x=280、底下的接地端直上直下），
  直接从表连到端子会斜穿过绕组
- **`.eu-t` 首列写「电流<br>互感器<br>CT」会被挤成一字一行**，直接写「CT」
- **数字卡里的文案要短**：「绝缘电阻表 500 V」「兆欧级（≥0.5 MΩ）」会折成三行，
  改成「兆欧表 500 V」「≥ 0.5 MΩ」

**2.7 电动机**（第 2 章最后一节）：凭什么转 / 铭牌怎么读 / 星形三角形 / 坏了怎么查。
后面第 9、10 章整章都在讲电动机，这一节是地基。直流电动机只带一句 —— 现场 95% 是三相异步。

- **第 1 屏画的是旋转磁场**：三相波形 + 定子圆里一根绿箭头（磁场）和一根橙杠（转子），
  <b>转子明显慢一点点</b>。转差固定取 4%。**画面必须慢放**（SLOW=20）——
  1440 r/min 是每秒 24 转，照实画就是一团糊，画布上写明了慢放倍数
- n₀ = 60f/p 只有 **3000 / 1500 / 1000 / 750** 这几个值（p 是整数）。
  **看到铭牌 1440 就知道是 4 极机** —— 这个反推现场常用，写进了 .bet
- **第 3 屏的眼是端子的错位排法**：上排 W2 U2 V2、下排 U1 V1 W1，
  <b>三块连接片竖着插正好接成三角形</b>（U1-W2 / V1-U2 / W1-V2 天然上下对齐）。
  记法钉死成「**横着两块 = 星形，竖着三块 = 三角形**」
- Y 相电压 220 V、△ 相电压 380 V，**△ 接的功率是 Y 接的 3 倍**；
  转矩正比于电压平方，(1/√3)² = 1/3 —— 星三角降压启动的电流和转矩都降到 1/3，两个都是 1/3
- **第 4 屏是真诊断技能**：三相绕组电阻柱状图（比的是「平不平衡」不是绝对值）
  + 对地绝缘的对数刻度表（0.1~1000 MΩ，0.5 MΩ 画一条合格线）。
  四种情况：正常 / 缺相（一相 ∞）/ 匝间短路（一相偏小）/ 受潮（电阻正常但绝缘掉到 0.2 MΩ）
- **「嗡嗡响转不动」先查电源侧**，别先拆电机 —— 熔断器、接触器触点、端子、电缆断芯
  都会造成同样现象，量三相电压几分钟，拆电机要几小时

**这一节踩的坑**：
- **静态画布第一次进来是空白**（2.6 也有，一起修的）：`fitAll()` 里的 `s.fit()`
  会重设画布尺寸并**清空内容**，而它排在初始化那几行 draw 的后面。
  场景 1/3 在 rAF 循环里每帧重画所以看不出来，**静态的那几屏就是一片空白**。
  正确做法是**把静态屏的 draw 放进 `fitAll()` 里**（切页签也会再触发一次 fitAll，
  同样需要）—— 第 1 章那几节本来就是这么写的，我这两节抄漏了
- **满格的柱子（∞）读数要写在柱子里**，写柱顶上会顶到框标题
- **`.eu-t` 四列中文表，首列会被挤成一字一行**。这次的解法是**并列**：
  「三相电阻」和「对地绝缘」合成一列「表上读数」，四列变三列就正常了。
  （2.6 那次是缩短首列文案，两种办法都行，看哪一列最长）
- **接线盒上的「三块片竖着」不能做成浮动胶囊**，它正好压住第三根连接片；
  并进「接线盒」那行标题里就干净了
- **数字卡的文案要短**：「10 kV 三相 / 400 / 230 V」会折成三行，

### 3.5 验电器（sec/c3-5.js，2026-08-29）

四屏：为什么会亮（回路）→ 插座三个孔 → **不亮≠没电** → 感应笔与高压。
**这一节的眼是第 3 屏那一句：验电笔不亮，不等于没电。**
现场出人命的从来不是不会拿笔，是笔不亮就当停电了。

**数字口径（都有出处，别再重算）**：
- **氖管起辉约 60 V，低压验电笔量程 60~500 V** —— 题库 6-A 组两道题
  （第 119、252 题）就从下限和上限两头考这一个区间
- **书上写的是「12~500V」，和题库的 60~500V 冲突**。两个都对但说的不是一件事：
  **氖泡式是 60~500 V**（考试按这个），**电子式显示档位从 12 V 起**（12/36/55/110/220）。
  课文里把这两种笔分开写了
- 笔内限流电阻常见 1~2 MΩ，按 1 MΩ 算：**220 V ÷ 1 MΩ = 0.22 mA**，低于感知阈值（约 0.5~1 mA）
- **限流电阻一旦短路：220 V ÷ 人体 2 kΩ = 110 mA**，远超致命量级。
  所以「摔过/进水/有裂纹的笔一律不能用、绝不能自己拆改」不是保养建议，是保命的
- 参考量级：感知 0.5~1 mA、摆脱极限约 10 mA、50 mA 可致命

**第 1 屏把「你是回路的一部分」画出来了**：火线 → 笔尖 → 1 MΩ → 氖管 → 尾部 →
手 → 身体 → 脚 → 大地 → 变压器中性点接地，一条闭合 `Path`，电流圆点真的从小人身上流过去。
三种握法对应三个断点：手指没抵尾部 / 站在绝缘垫上 / 正常。
**沿用 circuit-basics 那条表达：圈没闭合 ⇒ 圆点全部静止变灰**，不是「流到断点消失」。

**第 2 屏「零线断了」是现场最隐蔽的一种**：零线断在配电箱到插座之间、插座上还接着用电器时，
零线这一头**经过用电器的电阻被拉到接近相电压**，于是 **L 孔 N 孔笔都亮而用电器不工作**。
判据写死成：**用电器不工作但两个孔都亮 → 先怀疑零线断路，别碰**。

**第 4 屏钉死一句：感应笔用来「找」，不能用来「判定停电」**。三种情形——
真带电（两支都报）/ 已停电但邻近电缆耦合出感应电压（**误报**）/ 带电但线在金属槽盒里（**漏报**）。
**漏报比误报危险得多。**

**这一节画布上踩的坑（都是截图抓出来的）**：
- **大地不能用 `C.okbg`** —— 那是「成功绿」，一大片绿会被读成「这里是安全的」，
  跟这一屏要讲的正相反。改成 `C.box` + 斜纹
- **`EP.coil` 是横着画的**，画在竖直导线上会横铺出去把旁边的「220 V」标注盖掉一半。
  竖直导线上的电源改成自己画的**交流电源圆圈符号**（圆 + 正弦），标注挪到右边空地
- **国标三孔插座下面两孔是「八」字形（顶端窄、底端宽）**，我一开始两个角度写反了，
  截图上成了倒八字。左孔顺时针、右孔逆时针
- **结论条的配色要按「正不正常」分，不能按「亮不亮」分**。火线孔笔亮是正常的，
  配琥珀警示色自相矛盾；真正该报警的是「零线断了导致 N 孔也亮」
- **静态屏留白要按最满的那一档排版**。第 4 屏原来主电缆在 y=126、结论条在 262，
  只有「情形 2」用得上中间那 130 px，另外两档就是一大片空白。
  重排成三条横带（邻近电缆 / 两支笔 / 主电缆），画布高度 306→248
- 第 4 屏两支笔的标签要**一左一右分开站**，都往上放必然撞；
  耦合虚线放**电缆左段**，把中间让给笔和标签

### 3.6a 万用表（上）（sec/c3-6a.js，2026-08-29）

四屏：认识面板 → 测电压＝并联 → 测电流＝串联 → 量程与读数。
**这一节的眼是两句话**：测电压并联、测电流串联；**黑笔永远插 COM，换档要换红笔的孔**。
万用表烧掉十次有九次是后一条没做到。

**数字口径（都有出处，别再重算）**：
- 数字表电压档**输入阻抗 10 MΩ**（DT830/DT9205 这一类的标称值）；220 V / 100 W 灯
  R = 220² ÷ 100 = **484 Ω**
- **电压档串进 220 V 回路**：I = 220 ÷ (10 MΩ + 484) = **22.0 µA**，灯上只剩 **0.011 V**，
  而表两端仍是 **220 V** —— **读数完全正常，灯却是灭的**。这是万用表最会骗人的一种错法，
  现场表现是「一接表设备就停，表一拿开又好了」
- **12 V / 100 Ω 回路**：不接表 120.0 mA；串入 mA 档（内阻按 **1 Ω** 估）**118.8 mA**
  （那 1.2 mA 的差叫**接入误差**）；红笔留在 VΩ 孔去串联 I = **1.2 µA**，读 0.00 mA、负载停转
- **电流档并在 100 Ω 两端**：表的 1 Ω 把负载短接，**12 A** 全从表里过，保险管熔断。
  同样这一下在 220 V / 380 V 上就是弧光
- **3½ 位表最大计数 1999**：2 V/20 V/200 V 档满量程 1.999/19.99/199.9，1000 V 档分辨率 1 V。
  **1.5 V 在四档上分别显示 1.500 / 1.50 / 1.5 / 2**（最后一档一格就是 1 V，
  好电池和没电的电池看着一样）；**220 V 只有 1000 V 档读得出来**，其余三档全是 OL

**第 3 屏的第三种情形，从「并到电源上」改成了「并在负载两端」**：
布局上表笔线不用绕过电源（绕不开导线），而且那才是真实的误操作 ——
想量「电阻上的电流」，就把两支笔跨在电阻两端了。

**第 2 屏的第三个按钮「跨在开关两端」是白送的一个技能**：闭合读 0 V、断开读 220 V。
反过来用就是**电压降法**（开关合上了两端却量到 220 V ⇒ 触点没接通），
3.6b 查线路故障的主力手段，这里先埋一句。

**这一节踩的坑**：
- **两支表笔的软线不能交叉，而交叉与否是拓扑决定的**：红孔（VΩ）在黑孔（COM）右边，
  所以**红笔必须接右边那个测点**；反过来接的话两条线怎么走都会打结
  （试过让谁走上面那条横线都躲不开）。`leadPair` 里的规则是**孔 x 大的走上面那条横线**，
  前提就是孔序和落点序一致
- **软线要接到笔杆尾端，不是笔尖**。接到笔尖上的话，线垂下来和笔身是断成两截的
- **小表 LCD 上读数要右对齐、档位字（DC/AC/mA）左对齐**，像真表那样分站两头。
  读数居中的话会跟左上角那几个字挤在一起（屏 2 的「AC V」＋「220.0 V」实测贴住了，
  把 mode 缩成「AC」才够）
- **画布 `EP.heading` 的副标题必须短（≤4 字）**：表身机身从 x≈110 起，
  「错误示范：串进去了」这种长度会被机身直接盖掉半截
- **`EC.battery` / `EP.cell` 自带 ＋/− 极性记号**，旁边的标注贴太近会读成「＋12 V」「−直流」，
  标注 x 要再让开 10px 以上
- **表笔落点要躲开闸刀拨杆**：断开时手柄末端能伸到开关中心 +24 px，
  跨在开关两端的测点用 ±30 会叠上去，改成 **±40**
- **同一行上的两个标注要按文字实宽算间距**：「100 W 灯」和「这里断开了」都放 y=200 时重叠，
  缩短成「100 W」「断开处」才分得开
- **分辨率这类文案的小数位数要跟档位走**：写死 `toFixed(2)` 把 0.1 V 印成了「0.10 V」
- 直流记号 **⎓（U+2393）仍旧不能写字面量**，自己画一条实线 + 三段短虚线
  （`dcMark`，老坑，这一节又用上了）

**2026-08-29 做 3.6b 时，这几个零件抽进了 `elec-parts.js`**：
`EP.jack` / `EP.probe` / `EP.meterUnit` / `EP.leads` / `EP.dcMark`·`acMark`·`ctMark`·`modeMark`。
3.7 钳形表、3.8 绝缘电阻表都要画表笔和表身，**每节各画一份的话几节课之间会长得不一样**。

### 3.6b 万用表（下）（sec/c3-6b.js，2026-08-29）

四屏：测电阻 → 通断与二极管 → 指针表 → 查一条回路。
上节讲「怎么接」，这节讲「怎么用它把毛病找出来」。
**第 4 屏是这两节的落点**：电压降法 —— <b>电压掉在哪一段，断点就在那一段</b>。

**数字口径（都有出处，别再重算）**：
- **在路测电阻**：R1 = 1 kΩ、旁路 R2 = 2 kΩ，并联 1000×2000÷3000 = **667 Ω**，比真值**小 33%**。
  规矩写成一句：**并联只会让读数变小** —— 所以在路量到偏小的值不能下结论，
  量到偏大或 OL 倒是可以直接判它断了
- 通断档一般 **30~50 Ω 以下才响**（各表不同）。**响 ≠ 完好**：
  一根 24 Ω 的电热管本来就在响的范围里，短路成 0.1 Ω 也照样响
- 硅二极管正向 **0.5~0.7 V**（本节取 0.55），锗管 0.2~0.3，LED 1.6~3；反向 OL。
  **正反都 OL = 断路，正反都很小 = 击穿**
- **指针表欧姆档**：偏转比例 **t = Rc ÷ (Rc + R)**，Rc 是该档中心值（＝表内阻），
  按 MF47 那一类取 ×1 档中心值 15 ⇒ **Rc = 15 × 倍率**。
  1500 Ω 在 ×100 档 t = 0.5，指针正好落在刻度正中间；在 ×1 档 t = 0.0099，贴死在 ∞ 端。
  **没调零 = 满偏电流不够**，本节用 t×0.88 表示：短接时指针停在「2」附近而不是 0
- 第 4 屏：220 V 回路，**故障段承担全部电源电压，其余段 0 V**。
  **跨灯量到 220 V 有两种含义，靠「灯亮不亮」区分**：亮 = 正常；不亮 = 电压送到了、灯本身坏了

**第 4 屏的四个测量位置是点画布选的**（他反馈①「想在图上直接点」的延续）：
四个 `EC.hot` 框，选中的 a=0.85、其余 0.22 —— 四个都画亮的话画面会乱。

**这一节踩的坑**：
- **二极管的图和文字必须对上，这是内容错误不是版式问题**。`EP.diode` 默认
  **阳极在左、阴极（银环）在右**；课文写着「红笔接的就是正极」，
  那「正接」这一档就必须 `flip:true` 把阳极翻到红笔那一侧。
  第一版没翻，屏幕上红笔明明搭在阴极上却显示 0.55 V —— **图自己打自己的嘴**。
  `node --check` 和坐标断言都查不出来，是逐屏截图看出来的
- **表笔线的走法改成几何判定**（`EP.leads`）：3.6a 那版「孔 x 大的走上面那条横线」
  到这一节的「跨熔断器」（两支笔都往左伸）就失效了。现在是试两种分配、
  真去算竖段和横段有没有相交，选不打结的那一种
- **指针表的欧姆刻度数字不能标满**：R−20 那圈上相邻两档的弧长最小只有 10 px，
  标 11 个必然叠字（0/1、100/200、200/∞ 三处全叠）。减到 8 个（0/2/5/10/15/30/100/∞）
- **弧内正上方不能放标题**：那儿是中心值「15」那个刻度数字的位置，
  「Ω」和一行说明画上去正好压住它。Ω 挪到表盘左上角，说明整行删掉（lead 里已经讲了）
- **表笔落点要落在元件外面的导线上**：熔断器管体 70~130，落点取 ±28 会把笔杆压在银帽上，
  改 ±36。同样的道理，标注也要躲开笔杆（「拆下一头」放 x=110 会被黑笔压住，挪到 92）
- **同一个数在一屏里的写法要统一**：`fmtR` 在 <1000 时输出「667 Ω」，
  而结论条和讲解卡里写死了「0.667 kΩ」—— 屏幕上同时出现两种写法，
  读者会以为是两个数。现在统一成 667 Ω，括号里补一句「2 kΩ 档上显示成 0.667」
- **换倍率就作废调零**（`S3.zero=false; S3.short=true`）是这一屏的教学眼，不是副作用 ——
  数字表没有这一步，指针表每换一档都得重来

### 3.7 钳形表（sec/c3-7.js，2026-08-29）

四屏：不断线怎么测 → 只能钳一根 → 钳三根查漏电 → 小电流绕几圈。
**这一节接的是 3.6a 那句「测电流必须断开电路串进去」** ——
现场大量场合停不了机、拆不了线，钳形表就是答案。
原理一句话：**钳口是可开合的铁芯，被测导线就是只有一匝的一次绕组**（电流互感器，
和 2.6 那一屏同源）。四屏全部是从这一句推出来的。

**数字口径（都有出处，别再重算）**：
- 2200 W / 220 V 单相设备 → **10.0 A**
- 钳口没合严（缝隙、铁锈、油污）：磁路多了段空气隙，磁阻变大，**读数偏小**，按 9.2 A 示意
- 单相钳住 L+N：两根大小相等方向相反，**读 0.00 A** —— 现场表现是
  「设备明明在转、钳形表却是 0」，多半是把整根电缆钳进去了
- 三相平衡每相 10 A：钳 1 根 10.0、钳 2 根 10.0（等于第三相）、**钳 3 根 0.00**
- 三根全钳又读到 0.5 A ⇒ 有 0.5 A 漏走了。**漏电保护器里装的正是这样一个零序电流互感器**，
  家用整定值一般 **30 mA**
- 小电流 0.35 A：钳口感应的是**安匝数**，绕 5 圈读 1.75 A ÷ 5 = 0.35 A，
  末位从 0.01 A（约 3%）变成等效 0.002 A（约 0.6%）

**这一节踩的坑**：
- **机身只有七八十像素宽，读数写死字号会溢出机身**。`clampBody` 里改成
  按机身宽自适应，并且**单位不进读数** —— 交给左边那个档位字（A~），
  这也正是真表 LCD 的排法
- **二次绕组只能画在环的正下方**（外端伸进机身顶部，像引线进手柄）。
  画在右下、左下都行不通：钳大环（三相三根一起钳）时会横跨下面那根被测导线，
  画在正右方则会跨过穿心的那根线。逐屏截图才看出来
- **钳口张开时导线里的电流箭头不能停**。第一版写成 `if(k!==0)` 才画流动 ——

### 3.8 绝缘电阻表（sec/c3-8.js，2026-08-29）—— 第 3 章收尾

四屏：万用表量不出来 → 怎么接怎么摇 → 电压等级与判据 → 测完必须放电。
**这一节要回答的只有一个问题：万用表都有电阻档了，为什么还要单独一台表？**
两条理由钉死在第 1 屏：① 量程不够（好绝缘几百 MΩ 起，万用表最大 200 MΩ，量到头只有 OL）
② **测试电压不够**（万用表靠表内几伏电池；绝缘电阻的定义本身就是
「**在规定的直流试验电压下**」测得的值，不说电压这个数就没有意义）。

**数字口径（都有出处，别再重算）**：
- **低压设备/线路的判据 ≥ 0.5 MΩ** —— 低压电工最该背下来的一个数
- 电压等级：500 V 以下用 **500 V** 表；500~3000 V 用 1000 V；3000 V 以上用 2500 V。
  **选高了会把好绝缘击穿**（2500 V 摇 220 V 线路），**选低了考不出问题**（500 V 摇 10 kV 电缆）
- 手摇发电机额定 **120 r/min**，摇满 **1 分钟** 读数；60 r/min 时输出只有约 250 V
- 吸收比 R60 ÷ R15 ≥ 1.3 判受潮（只点一句，属更高一级内容）
- 残压按 500 V、等效电容 1 µF 算，储能 ½CU² = **0.125 J**
- 收尾顺序：**先取下 L 线 → 再停摇 → 对设备放电 → 才动手**。
  先取 L 线是防止设备电容里的电荷倒灌回表里把表打坏

**转速那一屏的说法要小心，别写成「转速低读数偏大」**：
兆欧表内部是**比率计**，读数本身对转速不敏感 —— 这正是它的设计优点。
真正的问题是**输出电压达不到额定值**，而判据是「在额定试验电压下」的值，
所以课文写的是「指针指到哪儿不是重点，重点是这次测量不作数」。

**拿不准的地方如实留白**：指针兆欧表刻度的方向（0 在左还是在右）各厂家画法有出入，
课文里**不对刻度方向下断言**，画面按最常见的「左 0 右 ∞」画。刻度按 t = R/(R+10) 铺，
所以右端非常密、低阻值那头反而分得开 —— 0.5 MΩ 的判据落在最左边一点点，画了个红标记。

**这一节踩的坑**：
- **画布 heading 又被机身盖了**（3.6b 那条老坑）：这次是屏 1，表的机身从 x≈84 起，
  「万用表电阻档 看不出来」直接被盖掉半截。标题一律缩到 3~4 字
- **兆欧表的 MΩ 字样只能放白表盘右上角**：弧顶正上方是刻度「10」的位置（和 3.6b
  指针表那条同源，第二次栽）
- **三个接线柱的柱名只能放柱子左边**：上方是白表盘的底边（深色字压上去看不清），
  正下方是测试线垂下来的路径（线会盖住字）
- **电机的名字不能放正下方**：那儿是接地线和接地符号
- **数轴最右那个刻度和单位会叠字**：「1000」和「MΩ」都在右端，单位得挪到数轴上方
- **手要真的碰到线芯**：第一版手悬在电缆下方 34 px，闪电两头都没连上，
  看着不像「碰到了」。手上移、闪电从线芯下沿连到指尖才对

  画布 308→292 才紧凑

### elec-theme.js —— 白天 / 夜间（2026-08-28 傍晚）

他的话：「把这个跟电工题库都加一个白天模式」。

**这不是「换个背景色」，是一次翻四套色板**，`ETheme` 一处统一做：

| 管什么 | 在哪 | 怎么换 |
|---|---|---|
| HTML | 各页 `:root[data-theme="light"]` | `<html data-theme>` |
| 画布 | `elec-canvas.js` 的 `PAL.dark/light` | `EC.theme()` |
| 元件 | `elec-parts.js` 的 `THEMED` | `EP.theme()` |
| 符号 | `elec-symbols.js` 的 `INK/FILL` | `ESYM.theme()` |

后三个都是「有就调」—— 题库页没有 EC/EP，课程页没有 ESYM。
偏好存 `localStorage` 的 `elec_theme`，**同域名下题库和课程页共用一个值**。

- **`<script src="elec-theme.js">` 必须放在 `<head>`**，晚了会先闪一下深色再变白
- **切换后靠 `dispatchEvent(new Event('resize'))` 让画布重画** —— 六节课本来就
  各绑了一个 `resize → fitAll`，借它一用，六个模块一个字没改。
  接不到 resize 的页面自己听 `elec:theme`
- **按钮自动挂载**（`autoMount`）：`.top` → 首页那块 `.hd` → 都没有就浮在右上角。
  13 个页面各去改一遍 JS 太碎。插的位置要挑：优先「整本书」链接左边，
  **再退到 `.sub` 前面** —— lab-circuit 的 `.top` 是 flex-wrap 而它的 `.sub`
  是 `flex:1 1 100%`，直接 append 按钮会被挤到第三行去（截图抓到的）
- **`--canvas` 必须和 `EC.PAL.<同名>.bg` 一模一样**，否则画布和它的卡片底之间会有一道边

**颜色藏在三个地方，只翻 CSS 变量表是不够的**（这次全踩了一遍）：
1. **CSS 里的字面量**：题库那 7 处 `.key{color:#16324f}` 是「配浅底的深色字」，
   底板换成暗色之后就和底糊成一片 —— 他截图报的「核心考点根本看不清」就是这个。
   规则定成：**块里的正文一律 `var(--tx)`，语义只由底色和标签表达**；
   每个语义色三档 `色 / -l 整块底 / -b 边框和标签底`
2. **画布代码里的 hex**：六节课里散了 **31 处** `'#1b232d'`/`'#12291f'` 这类面板底色。
   全部收进 `PAL` 的 `box/card/okbg/errbg/warnbg/accbg/voltbg`，逐个换成 `C.xxx`。
   **用整字符串替换（带引号），不要用正则改画图参数** —— 上次拿正则改 `r:` 
   把 `color:` 切成了 `colo,`，四个文件一起白屏
3. **函数的默认参数**：`EC.tag` 的底板、`EC.resistor` 的填充默认值都写死成 `'#fff'`

**这些不跟主题走 —— 它们是真实材质色**：仪表白表盘、c00 那块灯泡铭牌（`.plate`/`.pi`
深灰金属+白字）、电阻色环、国标线色、铜/钢/瓷/米黄。第四版那条规矩仍然有效。

**跟着翻的只有三类**：文字与引脚墨色、胶木机身（深底上要提亮才看得见轮廓）、
以及跟背景打交道的东西 —— 玻璃、压在画布上的浅色底板、导线。
其中**玻璃两个方向都要试**：深底上是「几乎透明 + 亮描边」，浅底上得反过来
「淡蓝灰半透明 + 深描边」，照搬深色那套的话白底上就是一个看不见的白球。

**符号是画进像素里的，切主题必须整页重画**，改 CSS 变量动不了它
（题库那 8 道图形题、`symbols-preview.html` 全集都要重画一遍）。

**滑杆不吃 `color-scheme`**：轨道和滑块是自定义样式（`::-webkit-slider-*`），

### 深色化那次留下的两个洞（2026-08-28 傍晚发现并修）

**① 四个页面根本没引 `elec-page.css`。**
`c00.html` / `lab-circuit.html` / `circuit-basics.html` / `magnet-field.html`
的内联 `:root` 里写着「颜色全部交给 elec-page.css」，**但 `<link>` 忘了加** ——

一直是**白底黑字配深色画布**。`grep -c 'elec-page.css'` 会返回 1 把人骗过去，
那个 1 是注释里的文字，**要 grep `<link[^>]*elec-page.css`**。
- 补 `<link>` 时**放在内联 `<style>` 之前**，让各页自己的规则能盖住共用表
- 补完 `lab-circuit` 的顶栏当场溢出：共用表里 `.top` 是**定高 46px**，
  而它的顶栏是两行（标题行 + `flex:1 1 100%` 的 `.sub`），得显式 `height:auto`

**② 白天模式刷新之后画布还是黑的。**
`elec-theme.js` 在 `<head>` 里跑（早了才不闪深色），可
`elec-canvas.js` / `elec-parts.js` / `elec-symbols.js` 都在 body 末尾才加载 ——
那次 `apply()` 执行时 `global.EC / EP / ESYM` **全都还不存在**，
三个「有就调」全部落空，画布色板永远停在 dark。
点按钮切换没这毛病（那会儿库早加载好了），**所以这个 bug 只在刷新后出现**。
修法是 DOMContentLoaded 时再 `syncLate()` 补一次三套色板 + 派一次 resize。

### elec-page.js + 动效层（2026-08-28）

**页签滑块**：`.tabs::after` 那根线靠两个 CSS 变量定位（`--tabn` 共几格、`--tabi` 第几格亮），
值由 `elec-page.js` 写。它全程用**事件委托 + MutationObserver**，
所以 `sec/c1-N.js` 那六个模块一个字都不用改；单页站切节时整排 tabs 是新节点，
观察到 `childList` 变化就重量一次。没接这段 JS 的老页面拿不到变量，
CSS 里有 fallback 让 `.tab.on` 的下划线照旧显示。

**动效只用来交代「什么变了、从哪来的」，不做装饰性运动**，所以只有四类：
切页签（下划线滑过去）、切场景（淡入 + 轻微上移）、卡片进场（同屏几张依次浮上来）、
状态变化时闪一下（`.num.bump`）。全部收在 200ms 上下，
`prefers-reduced-motion` 一律关掉。

### circuit-basics.html —— 回路 / 大地 / 触电 交互动画（2026-08-17）

四个标签页各自独立：①回路必须闭合 ②大地是一根看不见的导线 ③为什么升压送电 ④电位是相对的。
**全 Canvas**，四页共用一个 `Path`（折线路径）抽象 + 一个 rAF 主循环，只画当前页。
每页固定逻辑坐标（360×LH），`Stage.fit()` 整体缩放到容器宽度 —— 手机各种宽度不用重算布局，
点击热区反算也只有一行（`Stage.pick`）。

- **电流小圆点 = 一组沿路径的弧长值**，`s += v·dt` 取模循环。`dots()` 的 `skip` 区间用来
  让圆点绕开元件（开关/灯泡/电池）。这一个抽象同时供了①②③三页
- **「圈没闭合 ⇒ 圆点全部静止」是贯穿全篇的表达**，不是"流到断点才停"：
  ①断开时 `phase` 冻结、圆点变灰；②的 B 态路径画成灰虚线 + 静止灰点 + 红 ✗。
  物理上也正是这样，比"点冲向断点消失"更准
- **`glow()` 最里层只有 2.4px 且半透明**：高亮要让底下火线的红、零线的蓝、地线的黄绿透出来。
  早先 13px/8px + 一条 3.6px 实心，整条线被橙色盖死，国标线色（这一课要顺带记住的东西）全没了
- **②的地下段沉到 y=210（地面线以下 24px）**：走在地面线上看着只是线变粗了，
  沉进土里才看得出「电流真的在大地里走了一段」——这一页的全部意义就在这儿
- **②的人体关键点必须用绝对坐标（`GY-xxx`），别按 `footY` 另算一遍**：
  心脏标记曾按 `fy-122` 画，而路径胸口点是 `GY-122`，悬空时 `fy=GY-30`，红点浮到头顶上方 30px。
  C 态肩定在 `GY-128`、胸口 `GY-100`：肩再高就贴到头底、V 形变成「双手举过头顶」；
  下潜浅了就只是条起伏的线，「钻进胸腔」的意思没了。肩宽 24px（240/264）
- **③固定 P=100 万瓦、R=10Ω，四档实测（别再算）**：
  220V→4545 安 / 2.07 亿瓦（是要送的 **207 倍**，物理上等于送不出去，文案要如实说这条路走不通）；
  1万V→100 安 / 10 万瓦（10%）；10万V→10 安 / 1000 瓦（0.1%）；50万V→2 安 / 40 瓦（0.004%）。
  **柱长必须按对数**，线性的话后三档全成一条看不见的线，图注里要说明
- **③的疏密要「间距 + 粒径」双通道**（`GAP`/`DOT` 查表）：输电线只有 152px，
  纯靠间距的话 10 万伏和 50 万伏都只剩三四个点、分不出来
- **③的热浪要避开中间 x140~220**：电压和电流两行字标在那儿（y24/y38），热浪飘上去会从字里穿过
- **④刻度尺是固定的（0V 永远在正中），平移的是四个点**。刻度位置算过一次 `- cursh`
  就会出现「标着 +1.0V 的那一格上画着显示 0V 的点」，尺子和点的读数直接对不上（出图才看出来）。
  **0V 虚线只画到 x270**：山那边有它自己的海平面线（也是 0V）、高度不一样，
  横穿过去就成了「同一个 0V 画在两个高度上」

**验证手段是两套，各管各的，别只用一套**（2026-08-17 实测：这个页面一共改了 13 处，
其中 **5 处只有真机截图看得出来**）：

| | 塞 `vm` + mock DOM/canvas | 真机 Chromium 截图 |
|---|---|---|
| 快慢 | 秒级，改一行验一次 | 十几秒，要起浏览器 |
| 能查 | 几何坐标、数值、文案与屏幕数字是否一致、元素越界 | **版面**：文字被图形挡住、元素重叠、按钮换行、字号、emoji 实际宽度 |
| 查不了 | 一切 CSS 排版（没有排版引擎）；文字只能按估算宽度当色块 | —— |

被真机截图抓出来、而 95 项断言和光栅化图都放过的：小人的头骑在火线上、
「L 火线 220V」标注被头挡掉一半、红 ✗ 压在「脚离地（悬空）」上、按钮 2+1 换行且宽窄不齐。
**共同点是「两个东西挨在一起好不好看」，断言写不出来，色块图也看不出来。**

塞 `vm` 那套要自己写光栅化器，踩的坑下次直接复用别再犯：
- **一次描边要一次合成**：沿线逐个 disc 混合的话，相邻 disc 会把 alpha 累加到接近 1，
  半透明辉光被画得比浏览器浓得多 —— 我据此判断过「辉光太粗」，是错的。
  正解是先把覆盖率打进 mask 取 max，最后按 alpha 混一次
- **`fill()` 不清 path**：mock 里 fill 之后置空 `cur`，随后的 `stroke()` 就丢了，
  灯泡、变压器圆、方框全没了轮廓线
- `arcTo(x1,y1,x2,y2)` 至少要记成 `lineTo(x1,y1)+lineTo(x2,y2)`，只记终点会把圆角矩形画成三角形
- `createRadialGradient` 要能取到 stop 颜色，否则渐变被当成黑色 —— 灯泡光晕渲染成一个大黑盘
- DOM mock 的 `closest(sel)` **必须认 tagName**，页面里用的是 `closest('button')` 不是类名；
  漏了这一支，点击静默失效、B/C 两态根本没切过去（图上还是 A）
- 断言要**只取收敛后的那一帧**：`draw(i,n)` 会把 n 帧全累积进记录，
  拿 `[0]` 取到的是缓动途中的位置
- 断言别用 `includes('安全')` 这种宽匹配：鸟的标注里也有"安全"两个字，B 态那条一直是假阳性
