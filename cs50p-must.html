CS50P 必背清单

十讲里真正要记住的东西。代码下面的输出都是实际运行出来的。每讲详细练习在 复习课。

一定要记牢

以后写 AI 工具天天用，先把这一组背熟

第0讲print 显示，return 交回

print 只是印到屏幕上；return 才是把结果交回给调用的人，别人能接着用。

def add(a, b):
    return a + b

total = add(2, 3)
print(total * 10)
输出
50
第0讲input 拿到的永远是字符串

数字要先用 int() 转一下，不然 "5" + "3" 是拼接，不是相加。

a = "5"
b = "3"
print(a + b)
print(int(a) + int(b))
输出
53
8
第0讲f 字符串：把变量塞进文字

引号前加 f，花括号里放变量。拼提示词（prompt）全靠它。

name = "小明"
age = 20
print(f"{name} 今年 {age} 岁")
输出
小明 今年 20 岁
第1讲= 是存，== 是比

一个等号把值存进变量；两个等号问「相等吗」，用在 if 里。

score = 75
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
输出
及格
第2讲range 从 0 开始，不含结尾

range(3) 是 0、1、2，没有 3。

for i in range(3):
    print(i)
输出
0
1
2
第2讲列表：一串有顺序的东西

方括号；第一个是 [0]；append 往后加；len 数个数。

names = ["Ann", "Bob"]
names.append("Cat")
print(names[0])
print(len(names))
输出
Ann
3
第2讲字典：按名字找值

花括号，键: 值。用 ["键"] 取值；.items() 一对一对地遍历。

person = {"name": "Ann", "age": 20}
print(person["name"])
for key, value in person.items():
    print(key, value)
输出
Ann
name Ann
age 20
第2讲字典套列表：API 返回的样子

调大模型 API 拿回来的数据就长这样，一层一层往里取。

reply = {"choices": [{"text": "你好"}]}
print(reply["choices"][0]["text"])
输出
你好
第3讲try / except：出错不崩

可能出错的放 try，出了指定的错就跑 except。网络请求必备。

try:
    n = int("cat")
except ValueError:
    print("这不是数字")
输出
这不是数字
第4讲import 用库，pip 装库

自带的库直接 import；别人写的先在终端 pip install 名字。

import random
n = random.randint(1, 6)
print(1 <= n <= 6)
输出
True
第4讲requests：发网络请求

调 LLM API 本质上就是发一个请求、拿回 JSON。（这段要联网，没在这里跑）

import requests

url = "https://example.com/api"
r = requests.get(url)
data = r.json()
print(data["name"])
第6讲with open：读写文件

"w" 写（会清空），"a" 追加，"r" 读。with 用完自动关文件。

with open("note.txt", "w") as f:
    f.write("第一行\n")
with open("note.txt") as f:
    for line in f:
        print(line.rstrip())
输出
第一行
第6讲json：字典和文字互转

dumps 把字典变成文字（存文件、发请求）；loads 把文字变回字典。

import json
text = json.dumps({"ok": True})
print(text)
data = json.loads(text)
print(data["ok"])
输出
{"ok": true}
True

理解就行，用到再查

知道它是干什么的、能认出来就够

第5讲assert：代码自己检查自己

条件不成立就报 AssertionError。pytest 就是批量跑这种检查。

def square(n):
    return n * n

assert square(3) == 9
print("通过")
输出
通过
第7讲正则：按规律从文字里抓东西

re.search 找到就返回结果，找不到返回 None。写法现查或让 AI 写。

import re
m = re.search(r"(\d+)岁", "他今年20岁")
print(m.group(1))
输出
20
第8讲class：自己定义一种东西

__init__ 在创建时运行；self 指「这一个」对象自己。

class Dog:
    def __init__(self, name):
        self.name = name
    def bark(self):
        return f"{self.name}：汪"

d = Dog("旺财")
print(d.bark())
输出
旺财：汪

报错认得出

看最后一行冒号前那个词，就知道错在哪类

NameError

用了没定义的名字（多半是拼错了）

print(nmae)
报错最后一行
NameError: name 'nmae' is not defined
TypeError

类型不对，比如字符串加数字

print("5" + 3)
报错最后一行
TypeError: can only concatenate str (not "int") to str
ValueError

类型对但值不行，比如把 cat 转数字

int("cat")
报错最后一行
ValueError: invalid literal for int() with base 10: 'cat'
IndexError

列表下标越界

a = [1, 2]
print(a[5])
报错最后一行
IndexError: list index out of range
KeyError

字典里没有这个键

d = {"a": 1}
print(d["b"])
报错最后一行
KeyError: 'b'
IndentationError

缩进不对

if True:
print(1)
报错最后一行
IndentationError: expected an indented block after 'if' statement on line 1
SyntaxError

语法写错，比如漏冒号

if True
    print(1)
报错最后一行
SyntaxError: expected ':'
