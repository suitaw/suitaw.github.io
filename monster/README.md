# 怪兽冒险 Monster Quest

手机浏览器上就能玩的宝可梦风格回合制 RPG。纯前端、零依赖、零外部素材 —— 所有像素图、音乐、音效都由代码实时生成。

👉 打开方式：`https://<用户名>.github.io/monster/`（或直接用浏览器打开 `index.html`）

## 玩法

- **移动**：左下虚拟摇杆（也支持键盘方向键 / WASD）
- **A 键**：与人对话、调查、推进对话（键盘 Z / 空格 / 回车）
- **B 键**：打开菜单（键盘 X / Esc）
- 在**高草丛**中行走会遇到野生怪兽；先把对方打虚弱，再丢精灵球收服
- 被训练家**看到**会自动进入对战；怪兽中心可免费治疗，商店可补给
- 打赢**岩之道馆**拿到徽章后，可前往雷鸣洞窟，直通静谧湖的传说怪兽

## 内容一览

| 系统 | 说明 |
| --- | --- |
| 怪兽 | 20 种，含 3 条御三家进化线 + 1 只传说怪兽，每种有专属图鉴描述 |
| 属性 | 8 种属性与完整相克表（菜单内可随时查看） |
| 技能 | 40+ 招式，含威力/命中/PP、异常状态、能力升降、吸血、回复、先制 |
| 战斗 | 速度与先制决定出手顺序、会心一击、属性克制、STAB 加成、异常状态结算 |
| 成长 | 经验值与升级、升级学新技能（技能满 4 个时可选择遗忘）、等级进化 |
| 捕捉 | 三档精灵球、血量与异常状态影响捕捉率、摇晃判定动画 |
| 地图 | 2 座城镇、道路、森林、洞窟、湖泊 + 中心/商店/道馆/民居等室内地图 |
| 队伍 | 最多 6 只，超出自动进入保管箱，可与队伍交换、起昵称、调整首发 |
| 其他 | 图鉴收集、训练家卡片、道具商店、全灭回中心、自动存档（localStorage） |

## 文件结构

```
monster/
├── index.html   页面骨架与 UI 容器
├── style.css    移动端优先样式（含安全区、横屏适配）
├── data.js      属性/技能/怪兽/道具/地图/NPC 全部数据
├── sprites.js   程序化像素精灵生成（怪兽、人物、精灵球）
├── core.js      怪兽实例、成长与捕捉计算、存档、全局状态
├── battle.js    回合制战斗流程与动画
├── world.js     地图渲染、移动、交互、菜单、主循环
└── audio.js     WebAudio 芯片音乐与音效（可在菜单中开关）
```

## 技术要点

- 地图按 16px/格 预渲染到离屏 canvas（两帧用于水波/草浪动画），每帧只做一次缩放拷贝，手机上也能稳定 60fps
- 视野格数按地图尺寸与屏幕比例动态计算，小地图自动放大铺满，不留黑边
- 怪兽精灵由「体型 + 耳/角 + 尾 + 附件 + 花纹 + 配色」参数在 40×40 网格上对称绘制，自动描边与受光，20 种造型互不重复
- 存档写入 `localStorage`，进出地图、战斗结束、每 25 步与切到后台时自动保存
